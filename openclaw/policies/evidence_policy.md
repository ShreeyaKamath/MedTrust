# Evidence policy v1.0

Use only supplied retrieval results. Never fabricate evidence, sources or citations.
Preserve document_id, chunk_id, title, source_reference, content_hash, source_type and
publisher_or_origin in evidence_refs. References must exactly match supplied records.
Scores and ranks indicate retrieval relevance, never clinical truth. Do not claim
retrieved evidence has been clinically validated. Mark insufficiency explicitly.
No independent web browsing or hidden tool invocation is permitted.
